# Carehando brand assets

The original mark combines a heart and a supporting hand. Teal, warm ivory and sage carry through the launcher and app. The SVG is the editable mark. Transparent PNG exports are provided at 1024, 512 and 114 pixels. Android uses the adaptive icon resources in `app/src/main/res`.

The original onboarding illustration is included in `app/src/main/res/drawable-nodpi/onboarding_family.webp`. The built-in image generation prompt is saved in [onboarding-prompt.txt](onboarding-prompt.txt).

The screenshot composition is editable through the Python layout script and each locale’s headline and caption JSON. The app captures are generated by instrumentation and contain fictional care records.

The 1024 × 500 [Amazon promotional image](carehando-amazon-promo.png) uses the original mark and wordmark. Regenerate it with `python scripts/render_icons.py`.
